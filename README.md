# Healthy Weight Calculator

A single-page mini app built for MLH Global Hack Week: Builders Week — Challenge 1: Build a Mini App with Cursor.

Enter height, weight, age, sex and daily activity level, and it instantly calculates:

- **BMI** with Chinese adult standards (healthy range 18.5–23.9) and a visual scale
- **Healthy weight range** and ideal weight (BMI 21) for your height
- **BMR & TDEE** (Mifflin-St Jeor formula)
- **Daily calorie targets** for cutting, maintaining, or gaining
- **Body-fat estimate** (Deurenberg) and a daily protein target

## Run it

Just open `index.html` in any browser — no build step, no dependencies. All calculations run locally in the page and update in real time as you drag the sliders.

## Built with

Plain HTML, CSS and JavaScript in a single file, scaffolded and iterated with an AI pair programmer in the editor.
